# تحليل الفجوات (Gap Analysis)

## 1. نظرة عامة

توثق هذه الفجوة جميع الاختلافات بين نظام iHRIS القديم والنظام الحديث IHRIS Modern. يتم تصنيف كل فجوة حسب الخطورة وأثرها على المستخدم والبيانات.

---

## ملحق A: حالة GAP-001 — مكتملة (Closed)

> هذا الملحق إضافة توثيقية فقط؛ لم يُعدَّل أي محتوى أصلي في هذا التقرير.

| البند | القيمة |
|-------|--------|
| معرف الفجوة | GAP-001 |
| العنوان | إنشاء تقرير مخصص |
| المجال | إدارة التقارير |
| الحالة | ✅ **مكتملة (Closed)** |
| تاريخ التحديث | 05 نوفمبر 2026 |
| السيناريوهات (10 إجمالاً) | ✅ **10/10 متحققة** |
| محرك التنفيذ | `ReportEngine` حقيقي: SQL parameterized + whitelist + timeout 30s + حد 10,000 صف |
| رفض SQL injection | ✅ 8 سيناريوهات مختلفة |
| CSV | ✅ ملف صالح ببيانات عربية (`text/csv`, BOM, CRLF) |
| PDF | ✅ ملف صالح (`%PDF-`)، مع قيد معروف: بلا تشكيل عربي |
| Regression | ✅ 42/42 backend + 3/3 frontend |

### ما أُنجز

1. **محرك تنفيذ حقيقي** (`report.engine.ts`): بناء `WHERE`/`GROUP BY`/`ORDER BY` من تعريف JSON، معامَلات `$1..$n`، معاملات مسماة، `LIMIT` مُعامَل، `SET LOCAL statement_timeout = 30000`.
2. **قائمة بيضاء** (`report.whitelist.ts`): 25 جدولاً، حظر عمود `password`، regex صارم للمعرّفات، تحقق من `information_schema`.
3. **تصدير فعلي**: CSV (UTF-8 BOM + CRLF + quoting) وPDF (pdfkit) وJSON.
4. **حد معدل**: 10 تنفيذات/دقيقة/مستخدم.
5. **قاعدة اختبار منفصلة** `ihris_test_gap001` + ترحيل مطبَّق ومُسجَّل + rollback مُختبر + idempotency.
6. **اختبارات**: 12 محرك + 12 تكامل + 7 تحقق + 11 regression = **42 backend**، و**3 frontend**.
7. **توثيق**: ADR-004، `verification.md`، `evidence.md`، `07-TEST-EVIDENCE.md`.

### ما تبقّى خارج نطاق GAP-001 (لا يمنع الإغلاق)

1. تشكيل العربية في PDF (قيد تقني لمكتبة `pdfkit`).
2. دعم JOIN وRLS (مؤجلان).
3. الجدولة (GAP-L-001) — مؤجلة إلى P3 بقرار ADR-004.
