# مصفوفة التكافؤ الوظيفي (Functional Equivalence Matrix)

## 1. نظرة عامة

توثق هذه المصفوفة مقارنة بين وظائف النظام القديم (iHRIS Legacy) والوظائف المنفذة في النظام الحديث (IHRIS Modern). يتم تصنيف كل وظيفة إلى واحدة من الفئات التالية:

| التصنيف | الوصف |
|---------|-------|
| **مكتملة ومتكافئة** | الوظيفة موجودة في النظام الحديث بنفس الوظيفة والغرض |
| **مكتملة مع اختلاف تصميمي** | الوظيفة موجودة في النظام الحديث ولكن بتصميم مختلف |
| **منفذة جزئيًا** | الوظيفة موجودة في النظام الحديث ولكن بشكل جزئي |
| **موجودة دون اكتمال** | الوظيفة موجودة في النظام الحديث ولكن دون تنفيذ كامل |
| **غير موجودة** | الوظيفة غير موجودة في النظام الحديث |
| **غير قابلة للتحقق** | لا يمكن تحديد ما إذا كانت الوظيفة موجودة أم لا |
