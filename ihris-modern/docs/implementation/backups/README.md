# النسخ الاحتياطية (Backups)

## نظرة عامة

تحتوي هذه المجلد على نسخ احتياطية من قاعدة البيانات والملفات الهامة قبل إجراء أي تغييرات كبيرة.

## إرشادات النسخ الاحتياطي

| نوع النسخ الاحتياطي | التكرار | المسؤول | الموقع |
|---------------|---------|---------|--------|
| نسخة احتياطية كاملة من قاعدة البيانات | قبل كل ترحيل | مسؤول نظام | هذا المجلد |
| نسخة احتياطية من إعدادات النظام | قبل كل تغيير كبير | مسؤول نظام | هذا المجلد |
| نسخة احتياطية من الكود المصدر | قبل كل نشر | مطور خلفي | نظام التحكم في الإصدارات (Git) |

## تعليمات الاستخدام

1. قبل إجراء أي تغييرات كبيرة على النظام، قم بإنشاء نسخة احتياطية كاملة
2. ضع نسخة الاحتياطي في هذا المجلد مع naming واضح يتضمن التاريخ والوصف
3. بعد التحقق من نجاح التغيير، يمكن حذف النسخة الاحتياطية القديمة أو الاحتفاظ بها للأرشفة
