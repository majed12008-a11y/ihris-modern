# خطة المرحلة P4 - Certification (الاعتماد)

## نظرة عامة

| البند | القيمة |
|-------|--------|
| اسم المرحلة | P4 - Certification (الاعتماد) |
| المدة | الأشهر 7-12 من التوصيات الطويلة |
| المسؤول | فريق كامل |
| الحالة | مخطط |

## الأهداف

1. إضافة المصادقة الثنائية (2FA)
2. إضافة انتهاء صلاحية الجلسة تلقائياً
3. إضافة عزل بيانات حسب المؤسسة
4. اختبار شامل ونشر الإنتاج

## المهام بالشهر

| الشهر | المهمة | المسؤول | المخرجات |
|-------|--------|---------|----------|
| الشهر 7 | إضافة المصادقة الثنائية (2FA) | مطور واجهة أمامية + خلفي | واجهة تفعيل 2FA، API للتحقق من الرمز |
| الشهر 8 | إضافة انتهاء صلاحية الجلسة تلقائياً | مطور واجهة أمامية + خلفي | نظام انتهاء الجلسة، API لإدارة الجلسات |
| الشهر 9 | إضافة عزل بيانات حسب المؤسسة | مطور واجهة أمامية + خلفي + مسؤول نظام | نظام عزل البيانات، API لعزل البيانات |
| الشهر 10-12 | اختبار شامل ونشر الإنتاج | فريق كامل | نظام جاهز للإنتاج |

## dependencies

| العنصر | الوصف | الحالة |
|--------|-------|--------|
| مرحلة P3 مكتملة | يجب اكتمال مرحلة P3-COMPLETION قبل البدء في المرحلة P4 | غير Started |
| قاعدة بيانات PostgreSQL | قاعدة البيانات الأساسية للنظام الحديث | جاهزة |
| Prisma ORM | أداة الخريطة بين الكود وقاعدة البيانات | مثبت |

## معايير الخروج (Exit Criteria)

| البند | القيمة |
|-------|--------|
| المصادقة الثنائية تعمل | القدرة على تفعيل المصادقة الثنائية لمستخدم، التحقق من الرمز الثنائي عند تسجيل الدخول |
| انتهاء صلاحية الجلسة يعمل | القدرة على إنهاء الجلسة تلقائياً بعد فترة محددة من عدم النشاط |
| عزل بيانات المؤسسة يعمل | القدرة على عزل بيانات مؤسسة معينة، الوصول إلى بيانات مؤسسة معينة فقط |
| اختبار شامل ناجح | جميع اختبارات القبول للمرحلة P4 ناجحة |
| النشر الإنتاجي ناجح | النظام جاهز للإنتاج في البيئة الإنتاجية |
