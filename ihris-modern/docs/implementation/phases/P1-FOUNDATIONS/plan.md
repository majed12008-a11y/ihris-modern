# خطة المرحلة P1 - foundations (الأساسات)

## نظرة عامة

| البند | القيمة |
|-------|--------|
| اسم المرحلة | P1 - Foundations (الأساسات) |
| المدة | الأسابيع 1-4 من التوصيات الفورية |
| المسؤول | فريق التطوير (مطور خلفي، مطور واجهة أمامية) |
| الحالة | مخطط |

## الأهداف

1. إعداد البنية التحتية الأساسية للتنفيذ
2. معالجة الفجوات الحرجة الثلاث (GAP-001, GAP-002, GAP-003)
3. إضافة وظيفة إدارة المنشآت (إضافة، تعديل، عرض)
4. تأسيس بيئة التطوير والنشر

## المهام بالأسبوع

| الأسبوع | المهمة | المسؤول | المخرجات | الفجوات المستهدفة |
|---------|--------|---------|----------|------------------|
| الأسبوع 1 | تطوير نظام تقارير مخصص (الجزء الأول) | مطور خلفي | تصميم جدول التقارير، API للتقارير | GAP-001 |
| الأسبوع 2 | تطوير نظام تقارير مخصص (الجزء الثاني) | مطور واجهة أمامية | واجهة إنشاء وتعديل وحذف التقارير | GAP-001 |
| الأسبوع 3 | إضافة وظيفة تعديل وحذف المستخدمين | مطور واجهة أمامية + خلفي | واجهة تعديل وحذف المستخدمين، API للتعديل والحذف | GAP-002, GAP-003 |
| الأسبوع 4 | إضافة وظيفة إدارة المنشآت (إضافة، تعديل، عرض) | مطور واجهة أمامية + خلفي | واجهة إدارة المنشآت، API لإدارة المنشآت | GAP-004, GAP-005, GAP-006 |

## dependencies

| العنصر | الوصف | الحالة |
|--------|-------|--------|
| قاعدة بيانات PostgreSQL | قاعدة البيانات الأساسية للنظام الحديث | جاهزة |
| Prisma ORM | أداة الخريطة بين الكود وقاعدة البيانات | مثبت |
| Node.js + Express | إطار العمل للخادم الخلفي | مثبت |
| React + Vite | إطار العمل للواجهة الأمامية | مثبت |

## معايير الخروج (Exit Criteria)

| البند | القيمة |
|-------|--------|
| نظام تقارير مخصص يعمل | القدرة على إنشاء وتعديل وحذف تقارير مخصصة |

| واجهة حذف المستخدمين تعمل | القدرة على حذف المستخدمين عبر واجهة المستخدم |
