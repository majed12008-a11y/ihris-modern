# خطة المرحلة P2 - Core Functions (الوظائف الأساسية)

## نظرة عامة

| البند | القيمة |
|-------|--------|
| اسم المرحلة | P2 - Core Functions (الوظائف الأساسية) |
| المدة | الأشهر 1-3 من التوصيات القصيرة |
| المسؤول | فريق التطوير (مطور واجهة أمامية + خلفي + مصمم قواعد بيانات) |
| الحالة | مخطط |

## الأهداف

1. إضافة وظيفة إدارة الدورات التدريبية (تعديل، حذف، إضافة مؤسسة)
2. إضافة وظيفة إدارة درجات الرواتب ومصادر الرواتب
3. إضافة وظيفة إدارة طلبات التوظيف والتوظيف السابق والتعليم
4. إضافة وظيفة إدارة المزايا والملاحظات
5. إضافة وظيفة إدارة البيانات المرجعية

## المهام بالشهر

| الشهر | المهمة | المسؤول | المخرجات | الفجوات المستهدفة |
|-------|--------|---------|----------|------------------|
| الشهر 1 | إضافة وظيفة إدارة الدورات التدريبية (تعديل، حذف، إضافة مؤسسة) | مطور واجهة أمامية + خلفي | واجهة إدارة الدورات، API لإدارة الدورات | GAP-FE-007, GAP-FE-008, GAP-FE-009 |
| الشهر 1 | إضافة وظيفة إدارة درجات الرواتب ومصادر الرواتب | مطور واجهة أمامية + خلفي | واجهة إدارة درجات الرواتب، API لإدارة الدرجات | GAP-FE-010, GAP-FE-011, GAP-FE-012 |
| الشهر 2 | إضافة وظيفة إدارة طلبات التوظيف والتوظيف السابق والتعليم | مطور واجهة أمامية + خلفي + مصمم قواعد بيانات | واجهة إدارة الطلبات، API لإدارة الطلبات | GAP-FE-013, GAP-FE-014, GAP-FE-015 |
| الشهر 2 | إضافة وظيفة إدارة المزايا والملاحظات | مطور واجهة أمامية + خلفي | واجهة إدارة المزايا والملاحظات، API للإدارة | - |
| الشهر 3 | إضافة وظيفة إدارة البيانات المرجعية | مطور واجهة أمامية + خلفي | واجهة إدارة البيانات المرجعية، API للإدارة | GAP-M-008, GAP-M-009, GAP-M-010 |
