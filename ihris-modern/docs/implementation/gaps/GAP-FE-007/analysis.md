# GAP-FE-007 — تعديل دورة تدريبية

## الحالة
`TrainingForm.tsx` يدعم الإنشاء فقط، والقوائم المنسدلة تحتوي قيماً ثابتة (hard-coded).

## القرار
- توحيد النموذج للإنشاء والتعديل عبر `/training/new` و`/training/:id/edit`.
- تحميل المؤسسات/الحالات/التصنيفات من API.
- إرسال `version` عند التعديل → 200 + `version + 1`، وإظهار 409 عند التعارض.
