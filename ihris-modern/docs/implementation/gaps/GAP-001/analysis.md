# تحليل الفجوة الحرجة - GAP-001

## 1. معلومات الفجوة

| البند | القيمة |
|-------|--------|
| معرف الفجوة | GAP-001 |
| العنوان | إنشاء تقرير مخصص |
| المجال | إدارة التقارير |
| الخطورة | عالية |
| درجة الثقة | مرجحة |
| الأولوية | 1 (الأعلى) |

## 2. وصف الفجوة

النظام الحديث لا يحتوي على نظام تقارير مخصص مثل النظام القديم. لا يوجد جدول تقارير أو صفحات لتقارير مخصصة في النظام الحديث، مما يمنع المستخدمين من إنشاء تقارير مخصصة بناءً على احتياجاتهم.

## 3. الأدلة المرجعية

| معرف الدليل | العنصر | المصدر | النوع | مستوى الثقة |
|-------------|--------|---------|-------|-------------|
| EVID-203 | تحليل الفجوات | تحليل مقارنة | INFERENCE | مرجحة |
| EVID-306 | نظام التقارير المخصص القديم | جدول `config` يحتوي على إعدادات CustomReports مع تقارير مثل staff_list, staff_chart, facility_list, إلخ | FACT | مؤكدة |
| EVID-151 | سكريبت ترحيل البيانات | `migrations/mysql-to-postgres.sql` | FACT | مؤكدة |
| EVID-152 | إعدادات Docker Compose | `docker-compose.yml` | FACT | مؤكدة |

## 4. الفرق بين النظام القديم والحديث

### 4.1 نظام التقارير القديم (نظام مخصص كامل)

| البند | القيمة |
|-------|--------|
| نوع النظام | نظام تقارير مخصص (Custom Reports) مبني على جداول config |
| عدد التقارير المعرفة | 13 تقريراً معرّفاً (staff_list, staff_chart, facility_list, position_list, age_distribution, classification_breakdown, job_breakdown, nationality_breakdown, salary_list, staff_directory, home_contact, emergency_contact_list, position_open_duration, hires_per_year, retirement_planning) |
| أنواع العروض | PieChart, Bar, Scatter, Column, Table |
| قدرات التخصيص | عالية (تخصيص الحقول والعلاقات وعرض البيانات) |
| نظام تخزين التقارير | جدول config (نمط key-value) مع مسارات مثل config:modules/CustomReports/reports/* |
| جداول الإحصاء المسبقة (Zebra) | 4 جداول (zebra_facility_list, zebra_position_list, zebra_staff_chart, zebra_staff_list) |

### 4.2 نظام التقارير الحديث (قبل GAP-001)

| البند | القيمة |
|-------|--------|
| وجود نظام تقارير | ❌ غير موجود |
| جداول تعريف التقارير في Prisma Schema | ❌ لا يوجد نموذج Report أو ReportView |
| صفحات التقارير في الواجهة الأمامية | ❌ لا يوجد صفحة تقارير في frontend/src/pages/ |
| مسارات API للتقارير | ❌ لا يوجد مسار /api/reports في backend/src/routes/ |
| خدمات التقارير | ❌ لا يوجد خدمة تقارير في backend/src/services/ |

### 4.3 مقارنة شاملة بين النظامين

| الميزة | النظام القديم | النظام الحديث | الفجوة |
|--------|-------------|-------------|--------|
| نظام تقارير مخصص | ✅ موجود | ❌ غير موجود | فجوة كاملة |
| جداول تعريف التقارير | ✅ config table | ❌ غير موجود | لا يمكن تخزين تعريفات التقارير |
| جداول عروض التقارير | ❌ غير موجود | ❌ غير موجود | لا يمكن إدارة عروض التقارير |
| صفحات واجهة المستخدم للتقارير | ✅ موجود | ❌ غير موجود | لا يمكن الوصول للتقارير عبر واجهة المستخدم |
| API للتقارير | ❌ غير موجود (جزء من I2CE framework) | ❌ غير موجود | لا يمكن استدعاء التقارير برمجياً |
| تصدير البيانات إلى PDF/Excel | ✅ مدعوم | ❌ غير موجود | لا يمكن تصدير التقارير |
| جدولة التقارير | ❌ غير موجود | ❌ غير موجود | لا يمكن جدولة التقارير |
| تخزين تقارير مسبقة الحساب | ✅ جداول zebra_* | ❌ غير موجود | لا توجد جداول تقارير إحصائية |

## 5. التأثير على البيانات والوظائف

| البند | التأثير |
|-------|---------|
| التأثير على المستخدم | لا يمكن إنشاء تقارير مخصصة بناءً على احتياجات المستخدم |
| التأثير على البيانات | لا تأثير مباشر على البيانات |
| تأثير على العمليات | المستخدمون لا يمكنهم إنشاء تقارير مخصصة حسب احتياجاتهم، مما يحد من قدرتهم على تحليل البيانات واتخاذ القرارات |

## 6. الحل المقترح

| البند | القيمة |
|-------|--------|
| الحل | تطوير نظام تقارير مخصص يسمح للمستخدمين بإنشاء وتعديل وحذف التقارير بناءً على أي نموذج وحقل في النظام |
| الجهد المقدر | 4-6 أسابيع |
| الموارد المطلوبة | مطور واجهة أمامية، مطور خلفي، مصمم قواعد بيانات |
| المعايير المقبولة | القدرة على إنشاء تقرير مخصص، اختيار الحقول، تحديد العلاقات، اختيار نوع العرض (جدول، رسم بياني)، حفظ التقرير، وعرضه |

## 9. appendices: مقارنة تفصيلية بين جداول التقارير القديمة والحديثة

### 9.1 جداول النظام القديم المتصلة بالتقارير

| الجدول | الغرض | الأعمدة الرئيسية |
|--------|-------|---------------|
| config | إعدادات النظام والتقارير المخصصة | hash, path, type, value, children |

| zebra_position_list | قائمة الوظائف (تقرير) | غير مكتمل في ملف SQL |
| zebra_staff_chart | الهيكل التنظيمي للموظفين (تقرير) | غير مكتمل في ملف SQL |
| zebra_staff_list | قائمة الموظفين (تقرير) | غير مكتمل في ملف SQL |

### 9.2 جداول النظام الحديث المتصلة بالتقارير (بعد GAP-001)

| الجدول | الغرض | الأعمدة الرئيسية |
|--------|-------|---------------|
| report_definitions | تعريفات التقارير المخصصة | id, name, type, definition, createdBy, createdAt, updatedAt |
