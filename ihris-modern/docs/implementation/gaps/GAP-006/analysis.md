# تحليل GAP-006 — عرض تفاصيل منشأة

> التاريخ: 06 نوفمبر 2026 — قبل التنفيذ.

## 1. الحالة الفعلية قبل التنفيذ

| البند | الحالة |
|-------|--------|
| `GET /api/facilities/:id` | موجود ويعيد `facilityType` + `positions` |
| العلاقات الجغرافية | ❌ غير مُضمَّنة في الاستجابة |
| صفحة التفاصيل | ❌ غير موجودة |
| قراءة hr_staff | مسموحة (المنشآت بيانات عامة) |

## 2. المطلوب وفق ADR-006

1. إرجاع كل الحقول المرجعية: `country`, `region`, `district`, `county`, `facilityType`.
2. إرجاع `positions` المبسطة مع الحالة/النوع/القسم.
3. إرجاع `positionsCount`.
4. صفحة عرض تعرض كل ذلك مع تنبيه الحذف.
5. IDOR لا ينطبق: القراءة عامة لكل المصادَقين، لكن المصادقة مطلوبة.

## 3. القرار

توسيع `getById` ليشمل العلاقات، وإنشاء `FacilityDetail.tsx` وربطها بمسار
`/facilities/:id`، مع إتاحة القراءة لكل الأدوار.

## 4. خارج النطاق

- عرض سجل التدقيق في الواجهة.
- خرائط/إحداثيات (غير موجودة في المخطط).
