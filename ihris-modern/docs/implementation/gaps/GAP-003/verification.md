## 4. التحقق من بيانات الحذف الفعلية

تم التحقق عبر Prisma مباشرة بعد طلبات HTTP:

- `users.deletedAt` غير `NULL` بعد الحذف، و`NULL` بعد الاستعادة.
- `users.deletedBy = admin.id`.
- `users.deletionReason` يساوي السبب المرسل (بما فيه نص injection حرفياً).
- `user_audit_log` يحوي صفوف `delete` و`restore` مع `oldValues/newValues`.
- `reportDefinition` المرتبط منع الحذف (422) وبقي الصف سليماً.
