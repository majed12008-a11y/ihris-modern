# سكريبتات الترحيل المعلقة (Pending Migrations)

تحتوي هذه المجلد على سكريبتات الترحيل التي لم يتم تنفيذها بعد.

| الملف | الوصف | الحالة |
|-------|-------|--------|
| (لا يوجد) | - | - |

## تعليمات الاستخدام

1. ضع سكريبتات الترحيل الجديدة في هذا المجلد
2. بعد التنفيذ الناجح، انتقل السكريبت إلى مجلد `applied`
3. في حالة الفشل، انتقل السكريبت إلى مجلد `rollback` أو احتفظ به في `pending` للإعادة المحاولة
