## تعليمات الاستخدام

1. في حالة فشل سكريبت ترحيل، انتقل السكريبت الفاشل من مجلد `applied` إلى هذا المجلد
2. سجل سبب التراجع في الجدول أعلاه
3. قم بتشغيل سكريبت التراجع لإلغاء التغييرات
